# Keilanni Cirugías - Sitio Web

Sitio web premium para clínica de cirugías estéticas en Naucalpan, CDMX.

## 📋 Contenido

- **nueva.html** - Landing page principal (hero + servicios + doctores + CTA)
- **index.html** - Página de inicio alternativa
- **Servicios:**
  - `implantes.html` - Implantes mamarios
  - `lipo.html` - Lipoabdominoplastia
  - `rinoplastia.html` - Rinoplastia
- **Doctores:**
  - `doctor1.html` - Emmanuel Carbajal
  - `doctor2.html` - Omar Gutiérrez
  - `doctor3.html` - Jaime Álvarez

## 🎨 Diseño

- Tema de lujo: negro, dorado y crema
- Tipografía elegante (Cormorant Garamond + Inter)
- Responsive design
- Animaciones suaves y profesionales
- Integración WhatsApp para agendamiento

✅ CTA estratégicos para conversión
